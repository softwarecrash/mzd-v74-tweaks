CMU Tweaks

A ready-to-run USB launcher for Mazda CMU firmware 74.00.324.

Copy the contents of the development branch usb/ folder to the USB root, insert the drive, then confirm the notice with OK or choose Exit. The package includes its native ARM helpers; no compilation or assembly step is required.

One menu, discovered tweaks

Manifest groups become tabs. Select a tweak to read its description, prerequisites and status before installing or uninstalling it.

StatusMeaning
InstalledComplete installation
Not installedReady to install
UnavailableInstallation blocked; the menu explains why
BrokenIncomplete or damaged installation; automatic changes disabled

Included tweaks

SSH Access, Remove Safety Warnings and more.

This is a development proposal. The migrated shared runtime and four-state contract require a fresh vehicle test. Existing test evidence is documented separately.
